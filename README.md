# MailAI — AI Email Assistant

An AI-powered email tool that drafts and sends emails from plain-language descriptions.

## Features
- Describe what you want to say — Claude AI drafts the email
- Review and edit before sending
- Send via verified custom domain using Resend
- Saved contacts (personal and business)
- Sent history (last 50 emails)
- PIN-protected access

## Stack
HTML · Tailwind CSS · Claude API (Haiku) · Resend · Netlify Functions
